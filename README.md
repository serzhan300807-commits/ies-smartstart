# IES SmartStart

Independent student prototype introducing IES and Copernicus Berlin with multilingual guidance, self-check and FAQ support.

## Demo

🌐 Live website:

https://serzhan300807-commits.github.io/ies-smartstart/


## Project idea

Many students have questions about international study opportunities and do not always know where to start.

IES SmartStart is a simple orientation tool that helps users discover the programme, reflect on their interests and find possible next steps.

The project focuses on accessibility, clear guidance and responsible use of technology.


## Problem & Solution

### Problem

Students exploring international opportunities often need a simple first step to understand available information and possible ways to contribute.

### Solution

IES SmartStart provides a structured starting point through multilingual information, an interactive self-check and a local FAQ assistant.


## Features

🌍 **Multilingual interface**

The prototype supports three languages:

- English
- German
- Russian


🧩 **Self-check tool**

Users answer questions about their interests and receive possible directions for exploration.

The result provides orientation suggestions and does not represent an official evaluation.


💬 **Local FAQ Assistant**

A browser-based FAQ prototype with prewritten answers about IES topics.

No external AI model is connected.


📊 **Campaign analysis**

Illustrative data visualization demonstrating how communication channels can be compared using sample data.


🔒 **Responsible technology**

The project follows a privacy-friendly approach:

- No unnecessary personal data collection
- Browser-based local storage
- Transparent predefined answers
- Technology supports users instead of replacing human decisions


## Technologies

- HTML
- CSS
- JavaScript
- Responsive Web Design
- LocalStorage


## How it works

1. Users explore information about IES.
2. Users complete a short self-check about their interests.
3. The prototype provides possible contribution areas.
4. Users can explore FAQ answers and possible next steps.
